# Curral Ágil

Mini PWA do Sistema Raiz para pequenos produtores de leite.

## Tecnologia
- HTML
- CSS
- JavaScript
- IndexedDB
- Service Worker
- PWA offline-first

## Funções iniciais
- Cadastro de animais
- Controle de rebanho
- Funcionamento offline
- Instalação no celular
